# Pandas Assignment

This repository contains 13 Jupyter Notebook (`.ipynb`) files covering Pandas DataFrame and Series operations.

## Requirements
- Python 3
- Jupyter Notebook
- pandas
- numpy

## Install dependencies
```bash
pip install pandas numpy notebook
```

## Programs
1. DataFrame with product column
2. Row-wise and column-wise sum
3. Fill missing values with column mean
4. Drop rows containing missing values
5. Data aggregation by category
6. Total sales by category
7. Merge DataFrames
8. MultiIndex indexing and slicing
9. MultiIndex grouping
10. Apply a function to double values
11. Lambda function for row-wise sum
12. Convert text to uppercase
13. Extract first three characters

Open each `.ipynb` file using Jupyter Notebook, JupyterLab, or Google Colab and run the cells.
